一、核心结论

「外围AI交易裂缝引爆全球risk-off、A股科技全线杀跌、银行红利尾盘V型创新高护盘」——红盘率仅5%、跌超5%近2900家的极端普跌日，半导体天量失血109亿主线退潮确立，PCB/农业/短剧逆势局部抱团。

1. 全球共振杀跌，A股未能幸免，指数与个股同步失血

隔夜美股三大指数集体跌超2%（道指-2.19%/标普-2.02%/纳指-2.25%），今日日经225收跌5.06%（盘中一度跌超3000点，创约7个月新低）、韩国KOSPI跌5.21%（1/16以来最低，SK海力士-7%/三星-6%/软银-15%）。导火索是Anthropic上市首日冲高回落、做空机构指控AMD、FOMC偏鹰叠加负Gamma放大跌幅。A股全天低位震荡，沪指收 -1.23%（险守3500点，最低3500.83），深成 -3.09%、创业板 -3.54%、科创50 -3.12%（科创综指-5.23%），北证50 -4.85% 最弱。全市场红盘率 仅5%（上涨 313 / 下跌 5236 / 平 31 / 停牌 8），跌超5%约2860家 vs 涨超5%约54家（约53倍差），是本周最惨烈的普跌日。

2. 放量下跌，且是尾盘靠ETF天量资金强行护出来的「假V型」

两市成交 14222.00亿，较上日（13051.47亿）放量1170.53亿，结束了此前连续四日缩量。但放量是杀跌放量而非承接放量：上证50ETF华夏单日成交突破240亿、刷新历史天量，上证50盘中跌超2%后被尾盘快速拉起收红（+0.45%），建设银行、长江电力、工商银行、中信银行、中国石油尾盘齐创历史新高。这是权重护盘、题材失血的极端结构，不是全面企稳。

3. 资金：半导体天量失血109亿，吸金端全是防御与超跌局部

失血端 半导体 -109.11亿（全市场第一，天量），叠加通信设备-26.75亿、计算机设备-20.23亿、自动化设备-14.48亿、消费电子-14.26亿、光学光电子-10.28亿——科技硬件全线下 dump。吸金端 元件 +18.26亿（第一，PCB逆势）、白酒+4.92亿、数字媒体+4.66亿、农产品加工+4.39亿、国有大行+2.62亿、保险+2.61亿、渔业+1.84亿。核心特征：资金一边从半导体夺路而逃，一边挤进银行红利与PCB/农业/短剧几条局部避风港，是割裂而非切换。

4. 主线：半导体材料主线第4天退潮确立，银行红利尾盘创新高是唯一"持续性"方向

11/17启动的半导体材料/存储主线，今日全面崩塌——半导体-4.91%（仅6/183红）、光刻机-7.69%、靶材-7.88%、超节点-7.28%（主力-38.93亿），通富微电跌停、联合化学20cm跌停、天普股份2连跌停，前排后排双向杀跌，主线第4天退潮坐实。对立面是银行红利：建行/长电/工行/中信尾盘创历史新高，前排带得动后排（国有大行6/6全红、股份行8/9红），是当前唯一有广度、有持续性的方向，但属护盘防守而非进攻。

一句话定性：外围AI裂缝引发全球risk-off，A股放量普杀、红盘率仅5%，半导体天量失血109亿主线退潮；银行红利靠ETF天量尾盘拉出V型创新高，PCB/农业/短剧只在局部抱团，连板高度4板但3板断层。

领涨板块③：银行红利/中特估（国有大行+2.52% 6/6全红、保险+1.23%、股份行+1.18% 8/9红、证金持股+1.09%、汇金持股+0.50%；工行+3.30%、中信银行+3.09%、中国石油+4.67%，建行/长电/工行/中信尾盘创历史新高）· PCB/覆铜板（元件主力+18.26亿全场第一、覆铜板+0.20%主力+9.06亿；中京电子2连板、超声电子/澳弘电子/东晶电子/骏亚科技涨停、满坤科技20cm）· 农业渔业/养殖（渔业+0.79%主力+1.84亿、农产品加工+4.39亿、养殖业+0.35%；好当家7天4板、东方海洋、金新农6天3板、万向德农涨停）。

领跌板块③：半导体/光刻机/超节点（半导体-4.91%主力-109.11亿天量失血6/183红、光刻机-7.69%主力-10.74亿、靶材-7.88%、超节点-7.28%主力-38.93亿、SRAM-7.57%；通富微电/联合化学/天普股份跌停，海光信息/沐曦股份重挫）· 科技硬件全面杀（其他电子-6.99% 0/33、电子化学品-6.37%、军工电子-6.00% 0/60、通用设备-5.98%、消费电子-4.72%）· 机器人/周期材料（自动化设备-5.53% 0/82主力-14.48亿、小金属-5.19%、金属新材料-6.38%、电池-3.84%）。

三、市场情绪与量能

1. 广度与赚钱效应

红盘率 仅5%（上涨 313 / 下跌 5236 / 平 31 / 停牌 8），处于近一年极冷区间。涨停 30家（东财池28家）vs 跌停 68家（东财池54家），涨跌停连续第四日倒挂。涨超5%约54家（涨停30+涨7%以上16+涨5~7%的8）vs 跌超5%约2860家（跌停68+跌7%以上1064+跌5~7%的1728），亏钱效应约为赚钱效应的53倍——这是本周最极端的一天。跌幅密集分布在 2~5%（1820家）与 5~7%（1728家）区间，是全面、均匀的杀跌，而非个别板块闪崩。今日唯一的赚钱效应集中在四条线：银行红利、PCB、农业渔业、AI漫剧超跌反抽。

2. 量能

两市成交 14222.00亿，较上日 放量1170.53亿（+9.0%），结束连续四日缩量。关键在于放量性质：杀跌放量+尾盘ETF天量护盘（上证50ETF华夏成交240亿创历史天量）并存，说明分歧极大、筹码剧烈交换，不是增量资金进场做多。存量博弈下的放量下跌，通常意味着短线的恐慌出清，但也意味着承接盘成本区尚未确认。

3. 题材持续性（逐条写清）

  • 银行红利：持续性最强，但性质是护盘防守。 11/16工行首破"对子顶"创历史新高→11/17-19高位震荡蓄势→今日尾盘V型集体创新高（建行/长电/工行/中信/中石油）。龙头工商银行+3.30%创新高，后排国有大行6/6全红、股份行8/9红、银行概念23/42红——前排带得动后排，广度最好。但要注意：今天是靠ETF天量资金尾盘拉抬，属"护指数"的防守动作，不是题材进攻；且银行股连续新高后已进入高位区，追涨性价比低。
  • 半导体材料/存储/大基金：主线第4天，退潮确立、双向杀跌。 11/17材料启动→11/18大市值→11/19大基金/存储→今日全线崩塌。半导体-4.91%仅6/183红、主力-109.11亿天量失血；光刻机-7.69%（1/57红）、靶材-7.88%（0/5）、超节点-7.28%（0/28）。前排先杀：通富微电跌停、联合化学20cm跌停、天普股份2连跌停、海光信息/沐曦股份重挫；后排全绿：183只半导体股仅6只红。前排带崩后排、负反馈极强，主线宣告退潮。唯一逆势的华微电子涨停是摘帽独立逻辑（5/20已摘星摘帽），不构成板块效应。
  • PCB/覆铜板：逆势第1天，局部前排带后排。 龙头中京电子2连板（封单2.04亿、0炸板，质量好），后排超声电子/澳弘电子/东晶电子/骏亚科技涨停、满坤科技20cm，覆铜板概念+0.20%主力+9.06亿、元件主力+18.26亿全场第一。前排带得动后排（PCB内部），但带不动整个元件/科技板块——元件整体仍-2.94%，且20日主力仍净流出约300亿，属超跌反弹+资金抱团，非趋势反转。
  • AI漫剧/短剧：连续杀跌后的反抽，非新主线。 龙头华媒控股/龙版传媒涨停、果麦文化+10%、凡拓数创20cm，数字媒体+0.05%主力+4.66亿。但影视/短剧此前已连续多日暴跌（11/19数字媒体-5.52%），今日是"跌深了弹一下"的超跌反抽，无增量逻辑，持续性存疑，警惕一日游。
  • 机器人：脉冲一日游，后排推不动前排。 克来机电、长华集团盘中涨停，但自动化设备-5.53%（0/82全绿）、主力-14.48亿，板块整体在杀跌——这是孤立脉冲，板块没有跟上，前排带不动后排。
  • 华为算力：真视通独立妖股，板块整体退潮。 真视通4连板、荣联科技涨停，但通信设备-4.71%主力-26.75亿、超节点-7.28%主力-38.93亿——算力硬件全线退潮，真视通是脱离板块的独立连板，前排带不动后排，不宜视为板块重启。

五、题材涨跌分析

2. PCB/覆铜板（元件主力+18.26亿全场第一）

  • 代表个股：中京电子2连板、满坤科技20cm涨停、超声电子/澳弘电子/东晶电子/骏亚科技涨停。

3. 农业渔业/养殖（渔业+0.79%、农产品加工主力+4.39亿）

  • 代表个股：好当家涨停（7天4板，2.86元）、东方海洋涨停（3.75元）、金新农涨停（6天3板，3.76元）、万向德农涨停、东瑞股份+5.02%。
  • 涨跌逻辑：弱势市场中的低价防御 + 独立题材情绪炒作（渔业/种业）。这几只多为低价、小市值、带题材标签的情绪票，与基本面关联弱，属游资在普跌中寻找的"避风港"，波动风险高（详见第六节风险提示）。

  • 涨跌逻辑：外围费城半导体链暴跌（SK海力士-7%/三星-6%）直接传导 + 主线连涨3日后的获利兑现 + Anthropic/AMD事件打击AI估值。光刻机-7.69%（1/57红）、靶材-7.88%（0/5）、超节点-7.28%（0/28主力-38.93亿），前期最强的细分今日杀得最狠，是典型的高位拥挤筹码出清。

2. 科技硬件全面杀（其他电子-6.99%、电子化学品-6.37%、军工电子-6.00%）
