一、核心结论

「指数微跌、个股普杀、科技内部大分化」——半导体材料/存储/大基金逆势吸金独撑科创50翻红，传媒AI应用+算力高位+周期集体杀跌，红盘率仅11%的冰点普跌日。

1. 指数跌幅有限，但个股是全面失血的普跌

沪指全天低位震荡收 -0.28%（最低3547.94），深成 -0.71%、创业板 -0.79%；唯有 科创50 +1.83%（最强） 靠半导体权重逆势翻红，沪深300 +0.03% 靠权重护盘勉强收红。但个股层面是极致普跌：全市场红盘率仅 11%（上涨 649 / 下跌 4876 / 平 55 / 停牌 7），跌停 83 家 vs 涨停 28 家（涨跌停连续第三日倒挂且差距扩大），涨超5%约70家 vs 跌超5%约729家（约 10.4 倍差）。「指数 small red、个股 large green」的失真再度上演——今天赚钱效应只存在于半导体一条线。

2. 量能连续第四日萎缩，跌破1.31万亿

两市成交 13051.47 亿，较上一交易日（11/18 的 13697.02 亿）再缩 645.55 亿，连续四日缩量。半导体吸金、其余全线失血，是存量资金的极端高低切换，不是增量进场——这决定了科创50的独红缺乏广度支撑。

3. 资金：半导体近乎「一家独大」，科技其余分支与周期全线失血

吸金端 半导体 +28.23 亿（全市场第一，且断层领先），概念端 国家大基金持股 +31.93 亿 / 大基金二期 +22.48 亿 / HBM +21.00 亿 / 长鑫存储 +14.46 亿 / 大硅片 +8.47 亿 全线流入——半导体材料、存储、大基金三条子线同步获资金加仓。失血端高度集中在 IT服务 -26.50 亿（第一）/ 计算机设备 -16.14 亿 / 工业金属 -15.24 亿 / 通用设备 -13.28 亿 / 消费电子 -12.65 亿 / 电池 -12.17 亿 / 软件开发 -10.26 亿。核心特征：同为科技，半导体吸金、算力IT与消费电子失血，资金在科技内部做「二选一」的高低切；叠加周期、电池、军工同步失血，是「抽血式抱团」。

4. 主线：半导体材料主线第3天扩散，传媒短剧与算力双线退潮

11/17 启动的半导体材料主线，今日从「光刻胶/靶材」→「大市值权重」→「大基金/存储/大硅片」完成第三轮扩散，蓝箭电子20cm、华虹宏力+8.05%、燕东微+11.37%，后排江化微/格林达/大港股份/三佳科技/中京电子跟涨停，是当前唯一「前排带得动后排」的方向。对立面惨烈：昨日英伟达财报催化的算力租赁/超节点今日 -6.11%（0/28全绿）一日游崩塌，传媒短剧 -5%级别三次杀跌退潮确立。防御端白色家电 +1.38% 行业第一，但主力净流出 4.26 亿，属存量抱团而非增量。

三、市场情绪与量能

红盘率 11%（涨 649 / 跌 4876 / 平 55 / 停牌 7），处于近一年偏冷区间；跌停 83 > 涨停 28，涨跌停连续第三日倒挂且差距扩大；涨超5%约70家 vs 跌超5%约729家，亏钱效应约为赚钱效应的10倍。跌幅集中在 2~5%（2688家）与 0~2%（1459家）区间，是典型的「温和指数、普跌个股」结构。今日的赚钱效应几乎全部集中在半导体材料/存储一条线，不在这条线内的持股基本处于失血状态。

两市成交 13051.47 亿，较昨日（11/18）再缩 645.55 亿，连续第四日缩量并跌破1.31万亿。缩量普跌 + 单点抱团 = 存量资金在半导体里做防御性集中，既没有增量进场，也没有全面撤离；一旦半导体情绪退潮，缺乏承接盘的问题会立刻暴露。
